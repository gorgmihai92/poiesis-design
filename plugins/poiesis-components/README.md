# poiesis-components

UI components that take their look from the poiesis-ui cells and their behavior from the poiesis-ux rules. Copy
the ones you need into a React project; to change how the whole interface looks, choose another style (quiet,
soft, crisp, bold) or preset, and every component follows.

Part of the Poiesis toolkits: research collects, insight connects, frontier explores, design creates
([poiesis-research](https://github.com/gorgmihai92/poiesis-research), [poiesis-insight](https://github.com/gorgmihai92/poiesis-insight), [poiesis-frontier](https://github.com/gorgmihai92/poiesis-frontier), [poiesis-design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-design
/plugin install poiesis-ui@poiesis-design
/plugin install poiesis-components@poiesis-design
```

Full guide: https://github.com/gorgmihai92/poiesis-design#readme
