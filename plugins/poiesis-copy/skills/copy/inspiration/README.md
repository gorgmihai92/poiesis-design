# Inspiration

Copy the user admires, read for what it does well. One file per source. Each is **good practice, never a
rule**: it shows a way to write that has worked, so the skill can borrow the move when it fits the product's
`voice.md`. Its wording is never reused, and a caution in one points to the rule it would break.

## Use
Read these when setting a voice or writing a landing page, an ad or onboarding; take the practices that fit
the product and say which ones you used. Ignore one that fights the product's voice or a rule.

## Add one
When the user names a page, site, campaign or book they admire: read it, then write `<source>.md` here from the
template below. Describe moves, not phrases: quote at most a few words to point at a move. Add a line to the index.

```md
# <Source> · <url or reference>

Read <date>. <What it is, one line.>

## What it does well
- **<Move, named in a few words>.** How it does it, and why that helps the reader. (Practice for: landing page /
  product copy / ads / email / voice.)

## Cautions
- <Something to avoid copying>, and the rule it would break (id).
```
