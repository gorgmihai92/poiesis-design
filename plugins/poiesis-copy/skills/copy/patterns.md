# Poiesis copy patterns

Ready shapes for the common pieces of copy, built on `rules.md` (ids in brackets). Examples show the shape, not
words to reuse; write each one from the product's `voice.md`.

## In the product

## Landing page

Sections in this order unless the project decides otherwise; each heading a statement (O1), each section one
point (O3).

1. **First screen (O2):** a heading that states the outcome or the belief; one line that says plainly what the
   product is and for whom; one main action, specific and low-commitment (B4); what it costs to try (Q1, Q4).
2. **Proof early, if real (Q2):** who uses it (names, logos, a sourced count), or the product itself in use.
3. **What it does:** 3–6 benefits, each a heading (benefit) + one or two sentences (how it works) + a picture of
   it (Q6). Name features in the reader's words; a branded name only next to a plain one (L1).
4. **What it won't do:** the choices it refuses, if they are real and kept; it answers a doubt in a line.
5. **Doubts answered (O3, O4):** price, effort to start and to leave, privacy, limits. A FAQ answers in full
   sentences where a bare "Yes" would hide a condition.
6. **Price (Q4):** total, what renews, how to cancel, next to the action.
7. **Last ask:** the same main action, with the reassurance that matters most.

Headings test: read only the headings in order. They should make the case alone.

## Ads and email

Character limits change; check the platform before shipping. Write in the longer language first (X6).

| Format | Limits (2026, check) | Shape | Rules |
|---|---|---|---|
| Search ad (Google RSA) | headlines 30, descriptions 90 | each headline true on its own in any combination; one with the product name, one with the offer, one with the action | O5, Q1 |
| Social ad (Meta) | primary text ~125 visible, headline ~40 | the first line does the work before "See more"; the picture and the text say the same thing | L2, O5 |
| LinkedIn ad | intro ~150 visible, headline ~70 | the reader's problem in their field's words, then the offer | L1, O5 |
| Email subject | ~40–50 visible on phones | what's inside, not a tease; preheader adds, not repeats | L2, Q1 |
| Email body | one message, one action | point in the first line, action as a button, why they got it and how to stop at the end | O3, Q4 |

## Inspiration

Good practice from copy the user admires is in `inspiration/`, one file per source: what each does well and what to
avoid. Read them for direction on voice and structure; they are not rules, and their wording is never reused.
