# Concise, Scannable, and Objective: How to Write for the Web (Morkes & Nielsen, 1997)

- **Source:** Nielsen Norman Group / Sun Microsystems study, 1997 · https://www.nngroup.com/articles/concise-scannable-and-objective-how-to-write-for-the-web/
- **File:** none
- **Licence:** web article; not stored.
- **Evidence:** empirical lab study · 51 web users, 5 versions of one travel site · **NN/g's own report read via a research summary**.

## What it says
- Against a promotional version: concise +58%, scannable +47%, objective +27% (mostly not significant), all
  three combined +124% on a composite usability score; task time 149 s vs 359 s, errors 0.10 vs 0.82.
- One site, 1997, small groups, a composite measure; designers and writers excluded.

## What it means for the plugin
- Supports concise, scannable text over promotional text (L4). Old and small, so a should.
