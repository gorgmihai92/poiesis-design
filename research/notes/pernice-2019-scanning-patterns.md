# Text Scanning Patterns: Eyetracking Evidence (Pernice, 2019)

- **Source:** Nielsen Norman Group article, 2019 · https://www.nngroup.com/articles/text-scanning-patterns-eyetracking/
- **File:** none
- **Licence:** web article; not stored.
- **Evidence:** practitioner eye-tracking, illustrated with single or few users · **article read via a research summary**.

## What it says
- Several scanning patterns: F, layer-cake (headings only, the most effective), spotted, marking, bypassing, and
  commitment (reading everything).
- People read fully when motivated: studying, following instructions, trusting the source, sure they are in the
  right place. Good subheadings help even then.
- Illustrations, not a measure of how common each pattern is.

## What it means for the plugin
- Headings that state the point (L2, O1); motivated readers read on, so don't cut what they need (O4).
